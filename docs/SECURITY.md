# Security

## Threat model

| Threat                                       | Where                      | Defence                                                                                                                                                                                                                                              | Evidence                                                                                                                                                                                                                |
| :------------------------------------------- | :------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Gemini key theft                             | Client bundle, logs, repo  | Key only in the server process (Secret Manager in production); production refuses to start without it; CI greps the built client for key shapes; gitleaks; the hygiene test fails on any key-shaped string in the repo                               | [`config.ts`](../packages/server/src/config.ts), [`verify.yml`](../.github/workflows/verify.yml), [`hygiene.test.ts`](../tests/quality/hygiene.test.ts)                                                                 |
| Prompt injection via description or question | `/api/extract`, `/api/ask` | Pattern pre-screen (no model call) → independent LLM judge in parallel → fenced untrusted text → enum-only response schemas → Zod re-validation                                                                                                      | [`detect-injection.ts`](../packages/server/src/guard/detect-injection.ts), [`screen-input.ts`](../packages/server/src/guard/screen-input.ts), [`fence-untrusted.ts`](../packages/server/src/prompts/fence-untrusted.ts) |
| Injection via names or place                 | `/api/coach`, `/api/ask`   | Member names and place are pattern-screened before the plan is built; they reach the prompt only inside the fence                                                                                                                                    | [`load-plan.ts`](../packages/server/src/routes/load-plan.ts), app test "instruction-like names"                                                                                                                         |
| Hallucinated or harmful AI output            | Coach and answers          | Number grounding (every number must exist in the engine's facts, Devanagari digits normalised), no links/e-mails/phones, no instruction-like text, `actionId` restricted to this plan; failures fall back to the engine summary or are withheld      | [`check-grounding.ts`](../packages/server/src/coach/check-grounding.ts), [`coach.test.ts`](../packages/server/src/coach/coach.test.ts)                                                                                  |
| Tampered numbers from the browser            | Coach and answers          | The server rebuilds the plan from the profile and its **own** forecast; browser numbers are never used                                                                                                                                               | [`load-plan.ts`](../packages/server/src/routes/load-plan.ts)                                                                                                                                                            |
| Quota abuse                                  | AI routes                  | 10 requests/min per client (configurable), data routes 60/min; keyed on the **proxy-resolved** `request.ip` with `trust proxy` = 1 hop, so a forged `X-Forwarded-For` cannot reset it                                                                | [`rate-limit.ts`](../packages/server/src/security/rate-limit.ts), app test "forged X-Forwarded-For"                                                                                                                     |
| Malformed or oversized input                 | Every route                | Zod on every body and query; 16 KB body cap; descriptions 15–2 000 chars, questions 5–300, places 2–80                                                                                                                                               | [`schemas.ts`](../packages/server/src/validation/schemas.ts)                                                                                                                                                            |
| Bad upstream data                            | Open-Meteo                 | 8 s timeout; responses Zod-validated; concentrations clamped to 0–2 000 µg/m³; ≥ 24 hours required; the client re-validates the forecast too                                                                                                         | [`open-meteo.ts`](../packages/server/src/air/open-meteo.ts), [`client.ts`](../packages/client/src/api/client.ts)                                                                                                        |
| Tampered saved state                         | `localStorage`             | Restored session re-validated with the server's own Zod schema; anything invalid is discarded                                                                                                                                                        | [`saved-session.ts`](../packages/client/src/state/saved-session.ts)                                                                                                                                                     |
| Information leakage                          | Errors, logs               | Sanitised errors (generic 500); structured logs never include user text, names, questions or answers                                                                                                                                                 | [`app.ts`](../packages/server/src/app.ts), [`log.ts`](../packages/server/src/logging/log.ts)                                                                                                                            |
| XSS, clickjacking                            | Browser                    | Strict CSP (`default-src 'self'`, `script-src 'self'`, no `unsafe-inline`, `frame-ancestors 'none'`), API CSP `default-src 'none'`; no `innerHTML`/`dangerouslySetInnerHTML` (enforced by the hygiene test); theme via CSS only, so no inline script | [`security-headers.ts`](../packages/server/src/security/security-headers.ts), e2e "production security headers"                                                                                                         |
| Transport and isolation                      | Browser                    | HSTS (2 years), COOP/CORP same-origin, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, `Permissions-Policy` denying camera, microphone, geolocation, payment, USB                                        | same                                                                                                                                                                                                                    |
| Privacy of location                          | Upstream                   | Coordinates rounded to ~1 km before they are sent to Open-Meteo or used as a cache key                                                                                                                                                               | [`open-meteo.ts`](../packages/server/src/air/open-meteo.ts)                                                                                                                                                             |
| Dependency risk                              | Supply chain               | `npm audit --audit-level=high` and CodeQL (`security-extended`) in CI; minimal runtime dependencies (express, compression, zod, @google/genai)                                                                                                       | [`verify.yml`](../.github/workflows/verify.yml), [`codeql.yml`](../.github/workflows/codeql.yml)                                                                                                                        |

## Health and safety content

Health alerts are general precautions from WHO and Ministry of Health advisories, written as
data ([`health-alerts.ts`](../packages/core/src/catalog/health-alerts.ts)). The coach is told
never to diagnose or name medicines, the UI says "not medical advice" beside every alert, and
the footer gives India's emergency number. The carbon-monoxide warning for coal, wood and
kerosene heaters shows regardless of the AQI.

## Data kept

Nothing about a family is stored on a server. The profile lives in the family's own browser.
The server holds only short-lived caches keyed by hashes.
